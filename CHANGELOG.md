## [0.1.0] - 2026-10-20

### Added

- Initial release of YTM Hybrid - Native YouTube Music Desktop Client
- YouTube Music streaming with WebView authentication (SAPISID/3PAPISID cookie-based)
- Native ytmusic-rs implementation for YouTube Music API integration
- Gapless playback with audio normalization
- Synced/karaoke lyrics support from YouTube Music and LRCLIB
- Scrobbling with LastFM, ListenBrainz, LibreFM, and Maloja
- Discord Rich Presence integration
- Customizable themes, fonts, icons, transparency, and blur effects
- Cross-platform support: macOS, Windows, Linux
- Native GPUI-based UI built with Rust
- Local file playback support
- Queue management with shuffle and repeat modes
- Sleep timer functionality
